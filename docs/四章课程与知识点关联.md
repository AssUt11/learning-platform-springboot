# 四章课程与知识点关联

2026-11-10 补充课程结构与知识点定位。原有课程大多只导入了一章、1–2 个课时；此前正文扩展没有同时扩充章节。知识点入口只接受课时标题完全相同的结果，使“面向对象”等较短名称无法进入实际课程。

当前 41 门公开课程均按四章组织：概念准备与基础精讲、核心方法与条件辨析、案例推演与应用实践、综合任务与进阶训练。原有单章导入课程按内容单元重新归入前两章，每门新增四篇主题课时。总计 164 章、237 个已发布课时，每门 5–6 个课时，包含讲解、流程图、案例、练习与参考答案。已有课时编号、账号进度和素材绑定保留。归档课程不自动恢复，缺少录播的草稿课时仍等待真实素材。

课程配置位于 `backend/src/main/resources/catalog/course-curricula.json` 与 `course-curricula-technical.json`。每个主题同时声明实际覆盖的知识点别名，写入 `lesson_knowledge_topics`，按“大类、方向、知识点、课时”限定范围；入口同时支持精确标题与显式映射。多个结果展示课程和课时供选择，未配置的知识点仍明确提示未关联，不按模糊关键词跳转。学完映射课时后，原课时名称和关联知识点都会根据真实学习记录更新图谱进度。

`catalog_curriculum_seeds` 记录一次性增量导入。重启不重复增加章节或覆盖后续教师修改。已存在多个章节的自定义编排保留原排列；只对既有单章课程重新分配原始单元。
