## 数据与配置

演示账号密码、学习数据库、备份、上传录播、模型权重、运行日志和本机配置都不进入本次源码。演示数据脚本默认只读，需显式传入 `--apply` 才准备本机数据；不要把实际运行清单添加到 Git。

一键演示入口在源码和环境变量样例中默认关闭。显式准备本机演示设置后，它仅向本机请求提供固定演示身份的登录资料，再经过原有登录校验；前端构建不包含实际演示密码。公开注册仍不允许创建管理员。

已有数据库沿用后端增量初始化。`database/navicat_mysql.sql` 仅用于全新、可丢弃的数据库，升级时不执行该重建脚本。新克隆的源码需要自行准备数据库、模型服务和录播素材。
