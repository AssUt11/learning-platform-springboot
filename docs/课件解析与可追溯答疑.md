# 课件解析与可追溯答疑

迭代版本：v1.2.0-rc.1。更新日期：2026-11-08。

## 教师操作

1. 在教师工作台选择“管理章节与资料”，进入文档课时并上传文件。
2. 展开该资料 → “AI 课件解析” → “开始解析”。任务在后台排队，离开页面不取消任务。
3. 解析完成后核对原文件、页码/幻灯片/段落与正文，再点击“确认并用于 AI 答疑”。
4. 学生在相应公开课时的 AI 伴学中提问，回答下展示本次参考资料，可展开摘录并点击“查看参考原文”。

支持 PDF、PPTX、DOCX、UTF-8 TXT。旧版 DOC/PPT 可继续作为课程文件上传和手填摘要，自动解析前需转换格式。扫描件和纯图片暂不做 OCR；Word 仅标注实际正文段落，不编造页码。

解析限额：文件 20 MB、PDF/幻灯片 200 页或张、正文 50 万字符、最多 800 片段，每片段 900 字符以内。Office 压缩包另限制条目数、单项和展开总量；超限、加密、不支持或无可读文字时明确失败，不伪装成成功。

## 后台状态与数据

状态流程：`NOT_STARTED → QUEUED → PROCESSING → READY → CONFIRMED`。

`READY` 仅表示已得到预览，教师确认后才进入检索。资源版本改变后显示 `STALE`；旧确认版本可被 `SUPERSEDED`；无法处理时显示 `FAILED` 并支持重新提交。

`courseware_documents` 保存所属教师、公开课程 ID、课时、资料、资产指纹、SHA-256、状态与租约；`courseware_chunks` 保存真实位置与文本。任务单 worker 处理，通过数据库条件更新领取；五分钟租约过期后恢复排队，三次中断后明确失败。数据库状态使页面刷新与服务重启后仍能继续查看任务。

启动只增量建表及补充引用元信息字段，不执行基础数据库重建脚本。历史资料和用户账号沿用原数据；课程上下架和管理员审核条件不改变。

## API

| 接口 | 用途 |
|---|---|
| `POST /api/teacher/lessons/{lessonId}/assets/{assetId}/courseware/extract` | 教师提交后台解析 |
| `GET /api/teacher/lessons/{lessonId}/assets/{assetId}/courseware` | 查询持久状态与预览 |
| `POST /api/teacher/lessons/{lessonId}/assets/{assetId}/courseware/{documentId}/confirm` | 确认，body 为 `{ "versionHash": "..." }` |
| `GET /api/learning/courseware/chunks/{chunkId}?courseId=...&lessonId=...` | 登录后重新校验权限、版本并读取参考原文 |

教师目标来自登录账号与数据库归属关系，不接受客户端指定任意文件路径或远程 URL。课件路径必须落在平台上传目录内。学生引用入口使用当前课时 ID 和已登录凭据，忽略模型或事件中的外部 URL。

## 课时内检索与来源

这版使用中文关键词和段落相关性检索，范围限定在当前公开课时、教师已确认的文件。没有增加向量库或迁移 LangChain4j。

检索核对课程审核/上架、章节课时发布状态、文档课时类型、资料就绪状态、资产元信息与实际文件 SHA。文件更新、撤回、删除、课时改类型或课程下架后，旧片段不再作为新请求的参考资料；打开旧来源返回 404/410 时提示重新获取。

最多选取四个完整片段，优先纳入当前模型输入预算；放不下的片段不登记为引用。只有模型产生可见回答后才发送来源事件；连接失败、空答不发送，失败或取消不持久化引用。无检索命中时只提供原有当前课时上下文，不宣称找到了课件证据。

引用包含 `chunkId/documentId/assetId`、课程/课时、文件名、真实定位、版本、摘录与资料编号。回答中的 `[资料N]` 可对应来源列表的“资料 N”。“本次参考资料”表示输入给模型的上下文，不等于逐句验证了回答结论。历史保存身份与版本，原文必须重新授权读取；不通过历史接口重新下发已失效的旧课件摘录。

新增能力位于课时内 **AI 伴学**。独立 Agent 对话保持原有职责，未选择课程时不检索跨课资料。

## 模型评测与持续验证

[评测说明](../evaluations/README.md)包含 40 条中文合成样例、独立 Node 运行器与可选 Promptfoo 适配。分别记录离线契约、真实模型回答和业务功能测试，不能把离线通过写成模型通过。

```powershell
node --test evaluations/contract.test.mjs evaluations/provider.test.mjs
node evaluations/run.mjs --mode=offline
node evaluations/run.mjs --mode=live
```

真实模型基线见[2026-11-08 记录](../evaluations/BASELINE-2026-11-08.md)。评测不使用业务账号或数据库；当前严格 JSON、范围和引用判据保持不变，失败如实保留，不代表自然语言课时答疑的所有能力都失败。

新增 GitHub Actions 在 PR 中运行 Java 17 单测、Node 24 前端生产构建、明确列出的隔离浏览器回归与离线评测，不调用真实业务数据库或模型。真实模型评测需在本地显式执行。

## 依赖与范围

- Apache Tika Core 4.2.0：文件类型探测；不引入完整解析器集合。
- PDFBox 3.0.8：逐页提取 PDF。
- 现有 POI 5.2.5：逐幻灯片或 Word 正文提取；未整体升级 Office 依赖。
- H2：仅测试依赖，用于实际 SQL 队列与确认流程验证。
- 当前版本不包含扫描件 OCR、跨课程向量检索、模型重新训练或自动判定学生正式成绩。
