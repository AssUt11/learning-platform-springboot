# 课程封面素材来源

本轮课程卡片和详情共用 `CourseCover`，按课程标题识别学科。已有 `coverUrl`、`thumbnailUrl` 或 `posterUrl` 时优先显示实际图片；图片不可用时回退到本地学科插画。视频的 `fileUrl` 保持作为视频预览地址，不当作图片地址。

技术标志取自 [devicons/devicon](https://github.com/devicons/devicon)，已核对仓库 [MIT 许可证](https://github.com/devicons/devicon/blob/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6/LICENSE)。素材固定到提交 `32fe1d3b3f36ad11f90ab94f7db59738139c2bf6`，避免运行时依赖 GitHub 或 CDN。

本地文件位于 `frontend/public/course-art/devicon/`，许可证原文同目录保留。使用的 SVG 为原始版本：Java、Python、MySQL、Linux、Apache Spark、Selenium、C#、Vue、React、Spring、Docker、Kubernetes、Git、PyTorch、Redis、C++、Hadoop、TypeScript、C、OpenCV。下载路径均为该提交下的 `icons/{名称}/{名称}-original.svg`。

Devicon 的项目说明指出，产品名称与标志属于各自权利人；这里仅用于识别课程技术主题，不表示品牌背书。没有引入整个图标字体或新的运行依赖。

代码窗口、关系数据库、数据分区、概率分布、函数与切线、矩阵变换、树、网络、容器、测试清单、界面、柱线图、安全、芯片、图像识别、阅读页及书页构图由本项目用 SVG 原创绘制。它们用于解释课程主题，不是学习进度或实际分析结果。

课程详情复用方式：

```jsx
<CourseCover item={course} variant="detail" showBadge={false} />
```

组件返回无交互的铺满内容，点击行为由课程页原有按钮负责；封面是装饰，课程标题始终由外层可访问名称提供。卡片原有悬停视频预览保留；视频失效时继续显示主题封面。
