## 重跑

需先启动上述专用后端、前端、模型与两个隔离数据库。在 `frontend` 目录设置：

```powershell
$env:E2E_BASE_URL = 'http://127.0.0.1:5174'
$env:E2E_BACKEND_URL = 'http://127.0.0.1:8082'
$env:E2E_DB_PORT = '3307'
$env:E2E_DB_NAME = 'learning_platform_e2e_full_20261016'
$env:E2E_DB_PASSWORD = (Get-Content '../.runtime/e2e-20261016/mysql-password.txt' -Raw).Trim()
$env:E2E_ADMIN_PASSWORD = (Get-Content '../.runtime/e2e-20261016/admin-password.txt' -Raw).Trim()
$env:E2E_PATH_FLOW = '1'
$env:E2E_PATH_NEO4J = '1'
$env:E2E_AI_FLOW = '1'
npm run test:e2e
```
