# 学习规划对话与课程阶段

学生首次登录、尚未建立学习档案时，在首页之前进入 `/planning`。页面以选项为主，一次回答一个问题：学习方向、已有经历、学习目标、期望起点、每天投入时间。支持补充已学知识点、自定义方向和时间、返回修改及稍后规划。

## 使用流程

1. 登录后填写五个问题；每次继续都会保存回答，未提交的选择也按账号保留本机草稿。
2. 确认学习档案，调用当前已接入的大模型生成路径预览。
3. 预览按基础课程、中期课程、进阶课程展示目标、对应课程、推荐原因和预计时间。
4. 用户点击“采用路径并进入首页”后才保存为个人路径；预览不会覆盖正在使用的计划。
5. 首页“我的学习计划”提供下一步学习、完整路径和调整学习目标入口；账号菜单也可重新规划。

回答和预览按用户保存；修改回答会使旧预览失效。重复采用同一预览不会创建重复路径。模型暂不可用时保留回答，支持重试或先进入首页。自述“学过”仅用于推荐，不写入课时进度，不把知识点标绿。

## 三个学习阶段

| 编码 | 页面名称 | 用途 |
|---|---|---|
| foundation | 基础课程 | 概念和基础方法 |
| intermediate | 中期课程 | 知识连接、应用与巩固 |
| advanced | 进阶课程 | 深入原理和综合实践 |

首次启动为现有课程补充分级，已有分级不会在重启时被覆盖。教师上传或编辑课程时可选择学习阶段。课程列表支持阶段筛选；公共知识图谱进入具体方向后显示阶段分组，也可以单独筛选某一阶段。知识点原有身份与学习记录保留，胡克绿仍只表示真实学习进度达到 100%。

## 数据与接口

后端启动自动增量创建 `course_learning_stages`、`student_learning_profiles`、`learning_plan_previews`，无需重建数据库。

| 接口 | 用途 |
|---|---|
| GET /api/learning/profile | 读取学习档案、引导状态和有效预览 |
| PUT /api/learning/profile | 保存选项回答，更新版本 |
| POST /api/learning/profile/defer | 保存稍后规划状态 |
| POST /api/learning/planning/preview | 按回答版本生成预览 |
| POST /api/learning/planning/adopt | 确认采用本人当前版本的预览 |
| GET /api/learning/planning/current | 读取首页计划和实时学习反馈 |
| GET /api/courses?learningStage=intermediate | 按阶段筛选课程 |

原有 AI 学伴的路径分析也会参考学习档案。模型引用的课程必须在已审核、可学习的候选列表中，确认采用时再次检查课程可用性。Neo4j 暂不可用时，个人路径保存在 MySQL，恢复后可在路径页重试同步。
