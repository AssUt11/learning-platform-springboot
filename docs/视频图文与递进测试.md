# 视频、图文与递进测试

当前内置课程采用“录播讲解 + 加长图文 + 课程测试”的学习流程。课程测试只覆盖当前这门课程，不要求先学完站内其他课程。

## 临时视频（2026-11-12）

按用户当前要求，41 门公开课程暂时使用两个现有本地 MP4。原有两个录播保持不变，69 个待补的视频课时交替绑定复用文件并开放播放。视频文件共用本地地址，不重复复制；课时使用实际测量并向上取整的 106 秒或 311 秒，课程预计时长同步重算，既有图文与学习记录保留。

这些新增资源的文件名以“临时演示视频”开头，学习页会明确提示，素材清单中也区分为“临时演示，待正式录播”。后续通过原有教师上传流程替换为正式素材后，临时提示随新文件名自动移除。

本次为一次性增量操作，不在应用启动时自动绑定。脚本只处理公开课程预留的空视频草稿，不覆盖已存在的有效素材，重复运行不会重复添加。

```powershell
# 只查看当前可补充的课时数量
node frontend/scripts/seed-temporary-course-videos.mjs
# 按当前授权执行，事务内更新并先备份到 .runtime
node frontend/scripts/seed-temporary-course-videos.mjs --apply
```

脚本沿用 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD` 和可选 `APP_UPLOAD_DIR`。正式素材需求仍保留在清单中，演示视频仅用于体验播放及学习流程。

本次已应用到本地数据库：41 门公开课程均有视频，共 71 个已发布视频课时，其中 69 个为本次复用演示素材。已核对全部 71 个播放接口、两个本地文件的 HTTP Range 读取，并在真实浏览器中验证两种时长的视频解码、播放与结束进度保存；5 项相关生产构建页面检查通过。重复运行导入为零变更，原学习记录未改动。新版页面已随 8081 后端及 5173 前端启动，隔离验证服务完成后停止。

首次启动新版本时，增量补充 71 篇课时精讲：知识流程图、深入解释、分步案例、基础到进阶练习及参考解析。原有图文在原课时上扩展；已有录播增加独立图文课时。缺少素材的录播建立草稿课时，等实际文件到位后再发布。已有课时编号与学习记录保留，升级标记保证重启不会重复添加或覆盖后续教师修改。归档课程不自动恢复。

## 提供录播素材

录播采用用户提供的素材。可按 [课程录播素材清单.csv](课程录播素材清单.csv) 的“建议素材文件名”整理 MP4，并填写本地路径、实测时长；目前已有的两个录播无需重新提供。如果一节拆为多个视频，请一并说明对应顺序。

启动新版后可重新导出包含视频课时编号的清单，在 `frontend` 目录执行：

```powershell
node scripts/course-video-manifest.mjs
```

脚本只读数据库；连接设置沿用 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD`。教师在“管理章节与资料”中给对应视频草稿上传真实文件并填写实际时长，保存后按既有管理员审核流程发布。默认上传大小上限为 200MB。不能把图文阅读时长当作视频时长。素材未就绪时，图文可继续学习，课程测试会明确显示待补充的视频数量。

## AI 课程测试

学习页目录增加“课程测试 · 基础到进阶”入口。后端每次读取资格、出题落库和提交时重新核对当前课程发布状态与账号学习进度：

- 全部已发布视频和图文完成，且计划中的录播已发布，才能索题。
- 基础、巩固、进阶依次开放；每阶段最高成绩达到 80 分才开放下一阶段，也能回到已开放阶段练习。
- 按当前难度逐次索题，每轮接受 1–2 道有效单选题，从各课时讲义均衡选取资料，重复练习轮换段落和学习目标。基础检查概念，巩固考查应用，进阶考查综合场景与边界分析。
- 题目保存到账号，未交卷时继续同一轮；提交前不返回正确答案、依据和解析。后端计分，提交后展示并保存解析，重复提交不会覆盖成绩。
- 单课时练习与整课测试按 `practice_scope` 分开保存，彼此的难度记录不混用。

新增接口：`GET /api/practice/courses/{courseId}/assessment`、`POST /api/practice/courses/{courseId}/assessment/generate`。后者可传 `{"difficulty":"基础"}`，未指定时使用当前应练阶段。提交沿用 `POST /api/practice/{quizId}/submit`。

AI 出题需要已启用且可连接的模型服务；连接失败、超时或题目未通过原文依据校验时会显示错误，不保存无效题目。

## 验证记录（2026-11-10）

后端完整构建：177 项测试中 176 项通过、1 项按原配置跳过，无失败。浏览器检查 16 项通过，包含全课完成后开放、低分重练、逐级开放、刷新恢复、缺素材提示、失败重试和视频小数时长正常结束。生产构建在 1440、768、390 像素宽度下查看截图并检查无横向溢出。设计源码 lint 为 0 FAIL、0 WARN；技能自带的浏览器 inspector 需要 Node 22，本机 Node 18 无法运行，使用 Playwright 实际浏览器检查代替。

真实 LLaMA-Factory 模型完成基础、巩固、进阶三轮出题、原文核对、服务端计分、保存及重复提交验证。模型输出多余的闭合括号时仅做语法清理，不补题目字段或答案；课程测试由服务端为正确选项寻找讲义中的实际依据句，找不到则拒绝保存，重复选项仍拒绝。
