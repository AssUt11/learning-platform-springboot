# 接口与数据约定

[返回文档入口](README.md) · [总体方案](../知度课堂AI伴学-LangChain4j实施方案.md)

状态：现有行为的静态代码基线 + 待实施迁移约束。运行响应、全量错误码和数据库实际结构仍需回归核验。下列“拟新增”项不是已可调用接口或配置。

## 一、接口基线

| 方法与路径 | 当前用途 | 当前响应形式 |
|---|---|---|
| `POST /api/ai/tutor/chat/stream` | 课时流式答疑 | `text/event-stream` |
| `POST /api/ai/requests/{requestId}/cancel` | 取消本人请求 | `Result`，`data.cancelled` 为布尔值 |
| `GET /api/ai/conversations` | 本人会话列表 | `Result` |
| `GET /api/ai/conversations/{id}` | 会话详情 | `Result` |
| `DELETE /api/ai/conversations/{id}` | 删除会话 | `Result` |
| `POST /api/ai/messages/{id}/feedback` | 回答反馈 | `Result` |
| `POST /api/agents/guide` | 学习诊断 | 直接 JSON 对象 |
| `POST /api/agents/path` | 路径生成及快照保存 | 直接 JSON 对象 |
| `POST /api/agents/recommend` | 资源推荐 | 直接 JSON 对象 |
| `POST /api/agents/analysis` | 生成学习报告 | 直接 JSON 对象 |
| `GET /api/agents/reports` | 本人报告列表 | 直接 JSON 对象，包含 `reports` |
| `GET /api/agents/reports/{id}/download` | 报告下载 | 文件响应 |
| `DELETE /api/agents/reports/{id}` | 删除报告 | 直接 JSON 对象，包含 `ok` |
| `GET /api/learning/paths/latest` | 最新个人路径 | `Result` |
| `GET /api/learning/paths/{pathId}` | 路径详情 | `Result` |
| `POST /api/learning/paths/{pathId}/sync` | 重试图谱同步 | `Result` |

`Result` 成功响应为 `{"code":200,"message":"success","data":...}`。迁移时维持各入口现有包装形式，不把四卡片响应无版本地改成 `Result`。

所有身份来自 `Authorization` 的服务端验证。现有课时答疑要求学生身份，四卡片与个人路径使用现有 learner 校验；迁移应复用各自访问规则，不能无意放宽权限。

## 二、课时答疑请求

| 字段 | 当前校验 / 语义 |
|---|---|
| `conversationId` | 可不传；传入时必须为正数，并核验会话归属和课程范围 |
| `courseId` | 必填正数，使用平台公开课程资源 ID |
| `lessonId` | 必填正数，需通过当前课程与课时访问检查 |
| `message` | 去除首尾空白后非空，长度受 `messageMaxChars` 控制；当前默认 1000 字符 |
| `mode` | DTO 中存在；本次检查的应用调用链未用于模式选择，不能据此承诺新模式能力 |

以下仅为请求结构示例，课程和课时 ID 需替换为授权测试数据：

```json
{
  "courseId": 101,
  "lessonId": 1001,
  "message": "请结合当前课时解释依赖注入。"
}
```

`requestId` 由服务端生成。反馈请求的 `rating` 必须为 `1` 或 `-1`，`reason` 为反馈说明；不得修改他人的消息反馈。

## 三、SSE 事件基线

| 事件 | 当前载荷字段 |
|---|---|
| `conversation.created` | `conversationId`、`requestId` |
| `message.started` | `messageId`、`requestId`、`provider`、`model`、`knowledgeSource`、`graphNodeCount` |
| `message.delta` | `content` |
| `citation.added` | `sourceType`、`sourceId`、`title` |
| `message.completed` | `messageId`、`requestId`、`promptTokens`、`outputTokens`、`totalDurationMs`、`tokensPerSecond`、`neo4jUsed`、`graphNodeCount` |
| `error` | `code`、`message`、`requestId` |

`conversation.created` 在现有实现中也可用于已存在的会话，前端不能仅凭事件名称判断为新增会话。当前 `neo4jUsed` 在完成事件中取上下文可用性；迁移不能未经说明就把它当成“回答实际引用了图谱”的准确统计，精确证据使用应另行建模和验证。

迁移要求：

1. 保留事件名与既有字段类型，扩展字段必须保持前端兼容。
2. 成功持久化后才能发送完成事件；正常完成与失败、取消终态互斥。
3. 取消、断网、超时后，迟到回调不能追加正文或覆盖终态。
4. SSE 已开始时使用 `error` 事件表达失败；流建立前的 HTTP 错误按现有异常处理核验。
5. 取消后不增加未约定的新事件。是否取消成功由现有取消接口响应与已建立的流行为共同处理。
6. 首段文本已发出后，不透明地重放整次模型请求。

## 四、四类 Agent 返回基线

公共字段：`result`、`provider`、`model`、`requestId`、`toolsUsed`、`sources`、`graphUsed`、`promptVersion`。其中 `result` 为文字结果；工具和来源为列表；`graphUsed` 为布尔值。

- 路径成功返回增加 `learningPath`，内容来自路径保存服务，嵌套字段在 P2 补充实际响应快照。
- 报告成功返回增加 `downloadUrl` 和 `reportId`，继续走受保护的下载接口。
- 当前路径入口会保存生成快照；保存快照不等于学生明确采用计划。

拟新增内部类型：`DiagnosisResult`、`PathResult`、`RecommendationResult`、`ReportResult`。先转换成现有外部响应，再考虑有版本的字段扩展。`schemaVersion`、`snapshotId`、`warnings` 均需在实施时确定正式字段类型和默认值。

## 五、工具上下文与结果校验约定

- `userId`、允许访问的课程范围、`requestId`、截止时间、取消信号由服务端注入，不作为模型可指定身份参数。
- 各场景显式列出可用工具；单例对象上不存放可变当前学生，异步执行显式传递不可变上下文。
- `get_learning_profile`、`get_weak_knowledge`、`get_learning_resources`、`get_graph_prerequisites` 复用业务事实与固定查询。
- `toolsUsed`、`sources`、模型信息和预算消耗由真实执行记录产生，不由模型自报。
- 返回前核验必要证据、候选资源归属、实际引用、先修关系和字段长度。
- 播放进度不能标注为知识掌握率；图谱不可用不能标注为先修校验通过。

## 六、数据迁移登记

| 数据位置 | 已知限制 | 拟议改造 / 状态 |
|---|---|---|
| `ai_message` | 角色不包含工具调用与结果 | 运行时工具消息独立存储或仅留在任务内；待设计 |
| `ai_message_citation` | 来源类型未包含文档片段 | RAG 阶段扩展枚举或建立关联；待设计 |
| `ai_conversation`、`ai_usage_log` | 课程与课时字段非空 | 综合任务另建记录或显式迁移；不能填虚假 ID |
| `student_learning_paths` | 快照与同步状态，不表示采用 | 如引入采用计划，新增状态、版本及请求去重；待设计 |
| `agent_logs` | 当前四卡片任务审计 | 引擎、版本与总用量扩展；待设计 |
| `ai_agent_step` | 方案中的新表 | 步骤结构、状态与约束尚未实施 |

每项变更实施前填写：迁移文件、旧结构、新结构、默认值、回填、唯一约束、旧代码兼容及回退步骤。当前没有可执行迁移 SQL。

## 七、拟新增配置与待补契约

- `app.ai.engine=legacy|langchain4j`：项目自定义引擎切换建议，尚未实现，也不是 LangChain4j 自带配置。
- 场景级开关、任务总预算、综合任务接口、未知 Token 用量表达、路径幂等键均待在对应阶段确定。
- 尚未统一运行状态枚举；不得直接把 `partial` 写入只允许旧状态的列。
- P1 前补充旧 `guide` 成功和失败响应快照；P2 补充路径/报告嵌套字段；P3 补充完整 SSE 时序；P5 再定义综合任务的新接口。

代码依据：`AiTutorController`、`AiTutorApplicationService`、`AiChatRequest`、`AgentController`、`StudentLearningPathController`、`Result`；数据限制来自总体方案中的静态检查，实际数据库结构需在 P0/P2 核对。
