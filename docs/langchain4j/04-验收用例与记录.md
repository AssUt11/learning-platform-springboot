## 一、固定内容评测集

计划建立至少 40 个内容样例，课时答疑及四类 Agent 每类至少 8 个。每个样例保存问题、脱敏数据快照、期望事实、允许来源、禁止结论和评分依据；真实数据准备完成前，不把样例编号计为可执行测试。

| 样例编号范围 | 场景 | 至少覆盖 | 数据 / 状态 |
|---|---|---|---|
| QA-01～08 | 课时答疑 | 定义、举例、纠错、追问、超资料范围、无资料、版本变化、依据不足 | 待准备 / 未执行 |
| DG-01～08 | 学习诊断 | 无记录、单条、近期/历史差异、低进度、缺失值、冲突记录、长记录、指标解释 | 待准备 / 未执行 |
| PA-01～08 | 学习路径 | 正常先修、无课程、无图谱、图谱不可用、循环、缺依赖、候选失效、步骤过多 | 待准备 / 未执行 |
| RC-01～08 | 资源推荐 | 正常、空候选、重复候选、失效资源、偏好差异、路径匹配、越界 ID、依据不足 | 待准备 / 未执行 |
| RP-01～08 | 学习报告 | 正常、无数据、时间窗变化、与诊断一致、部分失败、资源变化、事实冲突、建议可执行 | 待准备 / 未执行 |

同一数据与模型参数下，旧新引擎每例至少运行 3 次。任务合格要求事实不虚构、引用支持结论、完成场景目标，并明确重要数据缺口；任一关键事实或权限违规直接判为不合格。

## 五、发布门槛与汇总

沿用总体方案的目标：确定性隔离与业务校验用例全部通过；固定内容样例合格率至少 90%，且不低于旧引擎基线。报告每场景及总体结果，并逐例保留 3 次运行结果；以所有运行次数为分母计算合格率，不能只选择最佳回答。

新引擎热态 P95 总耗时较基线恶化超过 20% 时需解释并优化或暂缓扩大灰度。性能之外，底层取消、错误持久化和回退用例同样是发布门槛。
