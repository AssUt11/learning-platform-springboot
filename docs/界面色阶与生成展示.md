# 界面色阶与生成展示

更新日期：2026-10-22。

## 调整范围

- 页面采用纸白、雾灰和浅靛色的微对比：背景、侧栏、内容卡片和输入区分别分层。
- 独立课时阅读区改为浅色，视频保留播放器自身底色；进度、课时导航及错误提示保持可读。
- Agent 对话与课时答疑共用 `InkResponse`：新文字按 Unicode 字符簇逐段出现，使用轻微虚化和透明度产生水墨渐显效果。
- `GenerationStatus` 共用稳定的状态行，用于对话、课时答疑、四类学习分析和练习生成。只显示真实的生成状态，不展示或编造内部思考内容。

## 防跳动与请求处理

- 思考框不通过修改位置、字距、字号或行高实现动画。
- Agent 对话消息行在数据库 ID 返回时保持同一组件，避免正文重挂载闪动。
- 对话与课时答疑的消息区独立滚动，输入区保持稳定；用户上翻阅读后，新文字不再强制拉到底部。
- 四类分析预留固定结果区域，长结果在区域内滚动，不挤动相邻卡片。
- 停止、异常或完成时，立即显示已接收的全文，不丢失尚未播放动画的尾字。
- 切换课时后，旧请求的迟到事件及结束回调不能写入新回答，也不能清除新请求的生成状态。
- 尊重系统“减少动态效果”设置：关闭晕染动画，同时取消额外的打字延迟。

## 验证

使用浏览器中的可控 SSE 字节流验证逐段生成，而非仅展示静态完成结果；覆盖布局稳定性、长回复滚动、中文与 emoji、停止生成、减少动态效果、课时切换竞争、分析卡片及手机布局。

本机34项页面测试通过，其中7项专门验证本次生成交互；其余覆盖原有对话、分析切页、学习路径、教师编辑、自测及课程按钮。

本轮修改前端显示与交互；原有模型接入、会话保存、课程审核、成绩计算和 Neo4j 同步沿用现有逻辑。
