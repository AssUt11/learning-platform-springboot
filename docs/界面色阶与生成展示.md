# 界面色阶与生成展示

更新日期：2026-11-05。

## 调整范围

- 页面采用纸白、雾灰和灰蓝的微对比：背景、侧栏、内容卡片和输入区分别分层。颜色来源统一到 `frontend/src/design-tokens.css`，旧模块变量映射到同一组语义色。
- 独立课时阅读区改为浅色，视频保留播放器自身底色；进度、课时导航及错误提示保持可读。
- Agent 对话与课时答疑共用 `InkResponse`：新文字按 Unicode 字符簇逐段出现，使用轻微虚化和透明度产生水墨渐显效果。
- `GenerationStatus` 共用稳定的状态行，用于对话、课时答疑、四类学习分析和练习生成。只显示真实的生成状态，不展示或编造内部思考内容。

## 防跳动与请求处理

- 思考框不通过修改位置、字距、字号或行高实现动画。
- Agent 对话消息行在数据库 ID 返回时保持同一组件，避免正文重挂载闪动。
- 对话与课时答疑的消息区独立滚动，输入区保持稳定；用户上翻阅读后，新文字不再强制拉到底部。
- 四类分析预留固定结果区域，长结果在区域内滚动，不挤动相邻卡片。
- 停止、异常或完成时，立即显示已接收的全文，不丢失尚未播放动画的尾字。
- 切换课时后，旧请求的迟到事件及结束回调不能写入新回答，也不能清除新请求的生成状态。
- 尊重系统“减少动态效果”设置：关闭晕染动画，同时取消额外的打字延迟。

## 验证

使用浏览器中的可控 SSE 字节流验证逐段生成，而非仅展示静态完成结果；覆盖布局稳定性、长回复滚动、中文与 emoji、停止生成、减少动态效果、课时切换竞争、分析卡片及手机布局。

本轮在 Vite 生产构建上完成48项可控接口/SSE浏览器回归，覆盖生成交互、对话与分析切页、登录失效、学习规划、知识进度、学习路径、教师编辑和自测。新增导航测试验证连续切页、历史前进后退、小屏菜单、Escape焦点恢复、动画API失效与减少动态效果。此处验证不等同于重新联调真实模型、MySQL或Neo4j。

本轮修改前端显示与交互；原有模型接入、会话保存、课程审核、成绩计算和 Neo4j 同步沿用现有逻辑。

## 转页与导航

- `usePageMotion` 在新页面内容提交后，为可见内容根节点添加180ms透明度过渡。顶部导航保持稳定；不等待动画回调更新路由，不重新挂载整个应用树，动画API异常时正常展示内容。
- 动画只改变透明度，避免影响视频、图谱坐标和固定控件。时间及缓动从共享变量读取；系统减少动态效果时跳过页面动画。
- 保留独立 Agent 的持续挂载、四类分析的会话级任务和已有返回位置恢复；课时答疑切课取消旧请求的逻辑保持独立。
- 1180px以下导航收为菜单，保留图标和文字；选中后收起，Escape关闭并恢复触发按钮焦点。当前页面使用 `aria-current` 标识，课程详情和学习页归属首页课程入口。
- 所有图标沿用Lucide，统一笔画与图文间距。常驻装饰旋转、悬浮抬升和大面积深色图谱背景收敛为静态浅色表面。
- 课程加载使用静态骨架保持内容区域，使用真实加载状态文字，不用伪造进度或闪烁渐变。
