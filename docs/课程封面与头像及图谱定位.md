# 课程封面、头像与图谱课时定位

更新日期：2026-11-07。

本轮保留原有学生、教师、管理员的模块与权限，完善课程发现、账号头像和知识图谱到课时的衔接。

## 课程封面与页面内容

- 课程卡片与课程详情共享 `CourseCover`。优先使用已有封面地址；图片失效时显示本地学科插画，不把视频地址作为图片使用。
- Java、Python、Linux、数据库、Spark 等技术课程使用本地 Devicon 标识与项目原创内容图示；概率、微积分、矩阵等科目使用原创 SVG 学科图示。
- 素材固定版本、本地保存，许可证随前端一起交付。课程详情提供“封面素材说明”；完整说明见[课程封面素材来源](课程封面素材来源.md)。
- 首页下方改为可操作的知识关系预览、AI 分析入口与账号学习概况。学习数量来自当前账号接口；未加载时显示破折号。
- 课程详情展示真实课时标题和学习目标，点击具体重点直接进入该课时；学习成果优先采用知识点，没有知识点时使用实际课时标题。
- 首页知识节点数量由分类树计算，替换写死的“100+”。

## 账号头像

顶部账号菜单 → **更换头像** → **选择照片** → 预览 → **保存头像**。

支持 JPEG、PNG、WebP，最大 5 MB、1600 万像素。浏览器将选中的照片居中裁剪并转成 PNG；服务端再次校验、解码和编码为 512×512 PNG。SVG、伪装文件和超限图片不保存。图片加载失败时使用居中的姓名首字。

- `GET /api/profile`：读取当前登录账号资料。
- `PUT /api/profile/avatar`：multipart `file` 上传头像。目标用户只取自登录 Token，不接受客户端传入用户 ID。
- 后端增量添加 `users.avatar_url`，不重建用户表。头像保存在现有上传目录下的独立 `avatars/` 子目录；替换只清理系统生成的旧头像文件。
- 登录返回头像地址；页面刷新通过账号接口恢复。头像不是仅存在浏览器缓存中的临时照片。

## 图谱到课时

原实现按知识点或方向关键词搜索课程并自动打开首项，可能丢失原知识点。现在使用：

`GET /api/knowledge/course-targets?category=分类&direction=方向&title=完整知识点标题`

分类、方向与课时标题精确对应，并检查课程已审核上架、章节和课时已发布、资源就绪及课程内容完整。

- 唯一匹配：直接打开 `/learn/{courseId}/{lessonId}`，显示具体课时标题。
- 多个同名课时：显示所属课程列表，用户选择后进入。
- 没有匹配：留在当前节点，提示查看方向课程，不自动选择模糊搜索结果。
- 切换节点或离开页面后，旧请求不能再改变导航。课时 URL 支持刷新与前进后退。

本机现有数据只读核对：**期望与方差：平均值和波动** 精确对应公开课程 24 下的课时 28，进入 `/learn/24/28`。课程名“考研概率统计：条件概率与随机变量”继续作为所属课程展示，课时标题保持知识点名称。

## 设计参考与验证

在 GitHub 查看了 [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 和 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)。本轮结合已有 `design-taste-frontend` 的应用界面规则实施，保留项目灰蓝与浅色阶体系；没有安装额外 npm UI 框架或全局技能。

验证包括前端生产构建、头像/封面/图谱/课程入口与原导航及 AI 状态的浏览器回归，以及头像存储、用户隔离、图谱精确匹配的后端定向测试。浏览器交互测试使用隔离模拟接口，不向真实业务数据库创建测试账号或写学习记录。

首页与课程详情在 1440、768、390 三种宽度检查布局与截图。视觉预览服务 18081 使用内存演示账号和课程样例，正式项目仍是 8081。
